# Contributing to Operational Intelligence Lab

Thank you for your interest in contributing. This project is designed to be a living playbook — it gets better as more practitioners share their experience.

## Who Can Contribute

- **AI Implementation Fellows** — Current and alumni Fellows
- **Pilot business participants** — Share your experience and results
- **Technical practitioners** — Improve prompts, skills, and methodology
- **Regional partners** — Adapt the framework for your area

## How to Contribute

### 1. Reporting Issues
- Use GitHub Issues for bugs in documentation, broken links, or incorrect information
- Label issues appropriately: `curriculum`, `prompts`, `methodology`, `templates`

### 2. Suggesting Improvements
- Open a Discussion thread for ideas, feedback, or methodology suggestions
- Clearly describe the problem and your proposed solution

### 3. Submitting Changes
1. Fork the repository
2. Create a feature branch: `git checkout -b improve/prompt-name`
3. Make your changes
4. Submit a Pull Request with a clear description

## Content Guidelines

### Prompts
- Include: purpose, when to use, required variables, expected output
- Test with at least 2 different LLMs before submitting
- Follow the format in [prompts/README.md](prompts/README.md)

### Curriculum
- Use clear, practitioner-friendly language
- Include hands-on exercises where possible
- Reference real-world examples (anonymized if needed)

### Mermaid Diagrams
- Use GitHub-compatible Mermaid v9 syntax
- Test rendering on GitHub before submitting
- Quote any node labels containing special characters

### Case Studies
- Follow the [case study template](templates/case-study-template.md)
- Include quantitative results and Rate of Improvement data
- Anonymize sensitive business information

## Code of Conduct

- Be respectful and constructive
- Focus on practical outcomes, not theory
- Share what works (and what doesn't) honestly
- Help others in the community succeed
