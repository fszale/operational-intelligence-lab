# Prompts Library

A collection of reusable, agent-ready prompts for operational AI implementation. Each prompt is designed to be used by Fellows, agents, or practitioners to analyze business data, design workflows, and measure outcomes.

## How to Use These Prompts

1. **Read the purpose** — understand when to use this prompt
2. **Fill in the variables** — replace `{{placeholders}}` with real data
3. **Run with any capable LLM** — these prompts are model-agnostic
4. **Adapt as needed** — these are starting points, not scripts
