# Skills Library

Agent skill definitions for common operational intelligence tasks. Each skill can be loaded into an AI agent to give it specific analytical capabilities.

## What Are Skills?

Skills are structured instruction sets that can be injected into an AI agent's context to give it domain-specific capability. Unlike prompts (which are one-shot), skills define **ongoing behavior patterns** for agents that work across multiple tasks.

## Available Skills

| Skill | Purpose | Use When |
|-------|---------|----------|
| [Business Data Analysis](business-data-analysis.md) | Analyze raw business data to extract operational insights | Processing CSV/spreadsheet data from a business |
| [Use Case Scoring](use-case-scoring.md) | Score and rank potential AI use cases | Deciding which bottleneck to automate first |
| [Outcome Probability](outcome-probability.md) | Estimate probability of achieving target outcomes | Assessing feasibility before committing resources |
